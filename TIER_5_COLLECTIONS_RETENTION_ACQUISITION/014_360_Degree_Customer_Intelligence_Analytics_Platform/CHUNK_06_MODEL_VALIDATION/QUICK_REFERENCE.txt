KEY METRICS EXPLAINED:
================================================================================

CV Mean vs Test Accuracy:
  Should be ≈ same (no gap = good generalization)
  If Test << CV = overfitting
  Example: CV=0.9193, Test=0.9198 ✓ GOOD

ROC-AUC Score:
  Range: 0.5 (random) to 1.0 (perfect)
  Target: >= 0.80 (good), >= 0.90 (excellent)
  Example: 0.9567 ✓ EXCELLENT

Stability Score (5 folds):
  Low variance = stable model
  Target: Std < 0.01
  Example: Std=0.0002 ✓ VERY STABLE

Confusion Matrix:
  TP (True Positive): Correctly caught defaults
  FP (False Positive): Wrong alerts (cost)
  FN (False Negative): Missed defaults (risk)
  TN (True Negative): Correctly identified good loans


VALIDATION CHECKLIST:
================================================================================

✓ CV Scores are consistent? (std < 0.01)
✓ Test matches CV? (diff < 0.05)
✓ ROC-AUC is high? (>= 0.80)
✓ Model is stable? (5-fold std < 0.01)
✓ Precision & Recall balanced? (F1 >= 0.80)
✓ Features are interpretable? (top 5 make sense)
✓ No overfitting? (CV ≈ Test)

If all ✓ = Model PASSED validation
