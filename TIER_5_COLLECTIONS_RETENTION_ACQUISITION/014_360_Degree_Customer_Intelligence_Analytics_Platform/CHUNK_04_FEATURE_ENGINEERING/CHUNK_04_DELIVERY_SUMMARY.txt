================================================================================
FEATURE ENGINEERING EXPLAINED
================================================================================

Categorical Encoding:
  - Converts categorical (text) variables to numeric (integers)
  - Label encoding: quality → {low:0, medium:1, high:2}
  - Preserves ordinal information when appropriate
  - Essential before training most ML models

Feature Creation:
  - Polynomial Features: Creates x², x³ for selected features
    Example: age² to capture accelerating age effects

  - Interaction Features: Combines related features
    Example: age × income (experienced high-earners different)

  - Ratio Features: Normalizes by related measure
    Example: debt / income (income-adjusted debt level)

  - Log Features: Compresses skewed distributions
    Example: log(income) for right-skewed income data

Feature Scaling:
  - Standardization: (x - mean) / std → mean=0, std=1
  - Normalization: (x - min) / (max - min) → [0, 1]
  - Essential for distance-based algorithms (KNN, K-means, SVM)
  - Improves convergence for gradient-based algorithms

Feature Selection:
  - Variance-based: Removes nearly-constant features (high threshold)
  - Correlation-based: Keeps features related to target (predictive)
  - Mutual Information: Captures non-linear relationships
  - Reduces dimensionality, improves model interpretability

Redundancy Detection:
  - Identifies feature pairs with correlation > 0.95
  - Indicates duplicate information
  - Remove one of pair to reduce memory, improve interpretability
  - Example: height_cm and height_m are 100% correlated

================================================================================
TROUBLESHOOTING
================================================================================

Q: "Division by zero in ratio features"
A: Already handled with np.where() - replaces invalid with 0

Q: "Log of negative values error"
A: Log features only created if ALL values > 0

Q: "Memory increased significantly"
A: Normal - feature creation increases data size. Use feature selection.

Q: "Script runs slowly with large datasets"
A: Expected for 1000+ features. Reduce sample size or polynomial degree.

Q: "Too many redundant pairs detected"
A: Use higher correlation threshold (e.g., 0.99 instead of 0.95)

Q: "Different results each run"
A: Polynomial/interaction features are deterministic. Randomness indicates
   data loading issue.

Q: "Cannot find chunk02_results"
A: Run CHUNK_02 first to generate cleaned datasets

Q: "Cannot import feature_engineering library"
A: Ensure running from CHUNK_04_FEATURE_ENGINEERING directory
