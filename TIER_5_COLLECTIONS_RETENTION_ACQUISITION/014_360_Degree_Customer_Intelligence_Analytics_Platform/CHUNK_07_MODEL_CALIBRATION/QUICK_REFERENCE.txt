KEY CONCEPTS EXPLAINED:
================================================================================

DECISION THRESHOLD:
  = Cutoff probability for predicting "default"
  Default: 0.5 (predict if prob >= 0.5)
  Optimal: ~0.35 (predict if prob >= 0.35)
  Effect: Lower threshold catches more defaults

COST-BENEFIT ANALYSIS:
  FP Cost = 1  ← Cost of false alarm (approve risky customer)
  FN Cost = 5  ← Cost of missed default (5x more expensive!)
  Why 5x? ← Missed defaults cause credit loss; false alarms just extra caution

THRESHOLD TRADE-OFFS:
  Lower threshold (0.3):
    + Catches more defaults (higher recall)
    - More false alarms (higher FP)

  Higher threshold (0.6):
    + Fewer false alarms (lower FP)
    - Misses more defaults (lower recall)

PROBABILITY CALIBRATION:
  = Are predicted probabilities accurate?
  Example: "60% likely" = actually ~60% of the time?
  Good if: Predicted ≈ Actual
  Target: Calibration error < 0.05
